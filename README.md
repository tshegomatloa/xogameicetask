# Tic Tac Toe / X & O – Version 1

## Project Overview

This project is a **Tic Tac Toe / X & O mobile game** developed using React Native.

The purpose of this task was to work through the development of the application from **Stage 0 to Stage 7**, following the provided development guide. Instead of creating the game completely from scratch, the task focused on understanding how the application develops progressively from one stage to another.

By completing each stage, I was able to see how different parts of the application were added and how the final working version of the Tic Tac Toe game was created.

## Technologies Used

The following technologies and tools were used during the development of this project:

- React Native
- Expo Go
- Visual Studio Code
- Git
- GitHub
- Node.js / npm

## Development Process

The project was completed progressively by working through **Stage 0 to Stage 7** of the provided development documentation.

At each stage, I:

- Added the relevant code to my project.
- Read the accompanying development notes.
- Observed the changes made between the different stages.
- Tested the application to make sure that it was working correctly.
- Committed my progress using Git.
- Pushed my commits to my GitHub repository.

This process helped me understand how a React Native application can be developed gradually instead of only focusing on the final version of the code.

## Testing

I used **Expo Go** to test the application during development.

Expo Go allowed me to run the application and check whether the Tic Tac Toe game was functioning correctly while I worked through the different development stages.

Testing the application regularly also helped me identify errors and problems with missing dependencies.

## Challenges Faced

One of the challenges I experienced during the development of the project was receiving errors because some of the required React Native packages were not installed.

In particular, I experienced issues related to **React Navigation** .

The application could not run correctly because the project was trying to use packages that were not available in the project.

I resolved these errors by installing the required dependencies and then restarting the Expo development server. After installing the necessary packages, I was able to continue testing the application using Expo Go.

This challenge helped me understand the importance of installing and managing project dependencies correctly when developing React Native applications.

## What I Learned

Through this project, I learned how to:

- Develop a React Native application progressively.
- Understand changes made between different stages of development.
- Test a mobile application using Expo Go.
- Identify errors caused by missing dependencies.
- Install required packages using npm or Expo.
- Use Git to track the progress of a project.
- Commit changes at different stages of development.
- Push a local project to a GitHub repository.
- Troubleshoot basic React Native and Expo errors.
